# Historias de usuario de RaizMixteca

## 1. Actores del sistema

### Productor

El productor podrá registrar sus datos, productos, lotes, fotografías e información relacionada con el proceso de producción. También podrá generar códigos QR asociados a sus lotes.

### Consumidor

El consumidor podrá escanear códigos QR y consultar información pública relacionada con el producto, lote y productor.

## 2. Historias de usuario

### HU-01 — Registrar productor

Como productor, quiero registrar mis datos, para identificarme dentro del sistema.

### HU-02 — Registrar producto

Como productor, quiero registrar un producto, para asociarlo con mi producción.

### HU-03 — Registrar lote

Como productor, quiero registrar un lote, para identificar una producción específica.

### HU-04 — Agregar fotografías

Como productor, quiero agregar fotografías a mis registros, para proporcionar información visual sobre mi producto y proceso.

### HU-05 — Registrar proceso de producción

Como productor, quiero registrar información sobre el proceso de producción, para proporcionar mayor información sobre el origen del producto.

### HU-06 — Generar código QR

Como productor, quiero generar un código QR para un lote, para permitir que los consumidores consulten información del producto.

### HU-07 — Escanear código QR

Como consumidor, quiero escanear un código QR, para consultar información sobre un producto.

### HU-08 — Consultar origen del producto

Como consumidor, quiero consultar el origen de un producto, para conocer información sobre su productor y lote.

### HU-09 — Consultar proceso de producción

Como consumidor, quiero consultar información del proceso del producto, para conocer cómo fue producido.

### HU-10 — Consultar datos de contacto

Como consumidor, quiero consultar un medio de contacto proporcionado por el productor, para poder comunicarme con él si estoy interesado.
