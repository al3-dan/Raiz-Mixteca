El proyecto

¿Qué es RaízMixteca?

RaízMixteca es una aplicación móvil orientada al registro y consulta de información de productores locales de la región Mixteca. El MVP contempla productores, productos, lotes, fotografías, información del proceso y consulta mediante códigos QR.

Productores

Registro de información básica del productor y relación con sus productos.

Productos y lotes

Organización de productos regionales y lotes con identificadores únicos.

Consumidores

Consulta de información pública sobre origen, proceso y lote mediante QR.

Trazabilidad

¿Cómo funciona?

1
Registro del productor

Se capturan los datos necesarios para identificar al productor.

2
Registro del producto

El producto queda asociado al productor correspondiente.

3
Creación del lote

Cada lote utiliza un código único, por ejemplo LOT-000001.

4
Proceso y evidencias

Se agregan datos del proceso y fotografías autorizadas.

5
Generación y lectura del QR

El código QR permite localizar el lote y mostrar su información pública.
